# 🎨 Virtual Painter

A real-time **Virtual Painter** that lets you draw in the air using your hand and index finger. The application uses your webcam to detect hand movements and converts your finger movements into digital drawings.

Built using **Python, OpenCV, MediaPipe, NumPy, and Streamlit**.

## 🚀 Live Demo

🎨 **Try the Virtual Painter:**  
https://virtual-painter-irpgx99q3yamtzqdcqs753.streamlit.app/

> Allow camera access when prompted to use the virtual painter.



## ✨ Features

- ☝️ Real-time index finger tracking
- 🎨 Draw in the air using hand movements
- 🖌️ Adjustable brush size
- 🌈 Multiple drawing colors
- 🧹 Eraser mode
- ✋ Gesture-based drawing control
- 📷 Browser webcam support
- ⚡ Real-time video processing
- 🌐 Deployed as a web application

### Available Colors

- 🔵 Blue
- 🟢 Green
- 🔴 Red
- 🟡 Yellow
- 🟣 Purple
- ⚪ White



## ✋ Hand Gestures

| Gesture | Action |
|---|---|
| ☝️ Index finger | Draw |
| ✌️ Index + middle finger | Stop drawing |
| 🖐️ Other positions | Stop drawing |



## 🛠️ Technologies Used

- **Python** — Programming language
- **OpenCV** — Computer vision and image processing
- **MediaPipe** — Hand and finger tracking
- **NumPy** — Numerical and image-array processing
- **Streamlit** — Web application framework
- **Streamlit-WebRTC** — Real-time webcam streaming
